# De fil en aiguille

Application iOS (SwiftUI) de questionnaires quotidiens en français : 5 questions par jour, reliées entre elles par association d'idées (« de fil en aiguille »), et un historique de tous les questionnaires.

```bash
open DeFilEnAiguille.xcodeproj   # choisir un simulateur ou son iPhone, puis ▶
```

Le projet Xcode est généré par [XcodeGen](https://github.com/yonaskolb/XcodeGen) depuis `project.yml` : après un changement de configuration (fichiers, réglages, polices…), lancer `xcodegen generate`.

Voir `CLAUDE.md` pour la structure, la direction visuelle et les prochaines étapes, et `docs/questionnaires.md` pour le contenu.
